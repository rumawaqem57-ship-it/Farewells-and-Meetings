# 历史辅助脚本

这三个文件从项目根目录原样迁入，不属于前端构建或当前角色卡维护流程。

- `add_locations.py`：向历史世界书追加地点条目。
- `add_cot_and_format.py`：向历史世界书追加思考与输出格式条目。
- `analyze_cot.py`：读取历史附件，输出 `cot_analysis.txt`；当时的结果现存于 `../../docs/history/cot_analysis.txt`。

前两个脚本仍写死原世界书的绝对路径；该目标文件当前不在项目根目录。它们使用追加操作，重复执行会重复写入条目。分析脚本仍指向本机历史附件，输出位置取决于执行时工作目录。这些路径和行为均作为历史原件保留。

日常开发只运行根目录 README 中的 npm 命令。将来若恢复这些脚本的用途，应先确认输入文件、输出位置及条目去重方案，再单独适配；本次未执行它们。
