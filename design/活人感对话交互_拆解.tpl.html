一句话结论：它的活人感不是来自 AI 多聪明，而是来自「玩家说的每一句话都被当成人话处理，并且立刻在角色身上留下可见痕迹」——台词接住你的语法、表情接住你的情绪、数字接住你的冒犯。三件事全部在 0.5 秒内回给你。

CHAPTER 02七个真起作用的零件

01输入框不是自由聊天，是「关键词投喂」

框里写着「点击输入关键词进行对话」。玩家能打字，但系统只认关键词。这是用自由输入的体感，换确定性的实现成本——两周做完的东西不可能接真 LLM 加状态机。

为什么有效：玩家体验到的是「我说了算」，不是「我从四个选项里挑一个」。自由度是感知问题，不是技术问题。
02台词会接住玩家输入的语法

玩家打了句「喜欢你」，她回：「不……你说喜欢我也不知道是喜欢什么啊，宾语呢？」——把对方的句子当成真的句子来挑毛病。

为什么有效：这是全片最狠的一手。AI 回得再漂亮，也只是「答得对」；吐槽你的语病，才会让人觉得「她在听我说话」，而不是「它在处理我的输入」。抄这个。
03眼镜反光＝情绪遮罩

被问到难堪的问题时，立绘的镜片直接变成不透明白色，眼睛消失，配台词「喜欢眼镜？」——一个纯白椭圆盖住眼睛就完成了「黑化 / 无语 / 不想让你看」。

为什么有效：零成本、零美术的强情绪信号。你只要准备一张「镜片高光」覆盖层，随时能叠到任何表情上。
04数值飘字必须落在立绘身上

「亲密度 -1」是左上角飘出的红字，2 秒淡出，和表情切换同一帧发生。

为什么有效：数值单独放在面板里＝系统日志；和表情同帧出现＝她被我弄不高兴了。因果被压缩进 0.2 秒，玩家自己就完成了归因。
05台词故意「说不完整」

「…………不管是爱还是喜欢都无所谓了」「……抱歉，有点吓到了」——大量前置省略号，短句收尾，句子长度普遍不超过 20 字。

为什么有效：完整、工整、有起承转合的句子是写作；半句话是说话。省略号还兼任情绪缓冲带，让表情切换有落点。
06立绘是可点击的实体，不是贴图

封面那张图底部写着「TIPS：点击立绘的各个部位查看详情」，点完弹出的是「果之宫黏度：Lv.1（微弱）· 纤细的腰肢，摸着没什么感觉」这类描述。

为什么有效：把「看」变成「碰」。角色从画面的一部分升级成可交互的对象，而且这一下不需要台词、不需要剧情，成本极低、反馈极强。
07她有自己的日程表

顶栏「DAY 1 / 体能 5/5 / 果实 10 颗 / 夜」、「次日」按钮、场景的昼与夜。

为什么有效：活人感的另一半是她不在等你。有时间流逝、有体力消耗、有资源，玩家才会觉得对话发生在「她的人生里」，而不是一个随时待命的对话框里。

CHAPTER 03视觉上它只做了三件事

配色（只有三色）

  • 墨黑：描边、名字标签、文字
  • 米纸：所有面板底色
  • 一点暗红：数值变化、强调

笔触（只有一种）

  • 铅笔排线 + 粗描边，全场景统一
  • UI 也用手绘描边，不做扁平矢量
  • 对话框＝漫画格子，不是系统控件

这套选择的好处不是「好看」，是可复制：一个人两周能画完的量，靠的是把美术压成单色线稿；而单色线稿反过来让「表情差分」变得极便宜——换个眉眼就是一张新表情，不需要重画光影。

这条对你最有用

你在做 monster girl 图鉴和固定角色立绘，走的是彩色精细插画路线，表情差分成本很高。视频的路子是反的：用低成本笔触换高密度差分。不一定要换画风，但可以借它的结构——把「表情」拆成可叠加的层（眼、眉、嘴、脸红、汗、镜片高光），而不是一张张整图。

CHAPTER 04搬到 koi 前端要改什么

你现在的 src/koi 已经有 CharacterStage（立绘舞台）、DialogueBox（对话框）、TypingText（打字机）、ChoiceBar（选项条），剧本行里也已经带 emotion?: string 字段（中文情绪标签，如「害羞」）。也就是说骨架已经比这个 Demo 完整，缺的正好是「活人感」那几块软组织。

TIER 1 · 半天

表情过渡 + 情绪遮罩 + 数值飘字

三件事都在 CharacterStage 这一层做完，不动剧本解析。

TIER 2 · 一天

台词「接住」玩家：回显原文 + 语法吐槽 + 关键词输入框

把玩家的输入当引用塞进台词，或者用正则判定语病后走吐槽分支。

TIER 3 · 两天

可点击立绘分区 + 状态描述卡

立绘切若干热区，点中出状态条。这条最出效果，也最费美术文案。

TIER 1：表情不能硬切，要「抖一下」

视频里的表情切换不是 crossfade，是先僵住 100ms 再换——所以你会觉得她「愣了一下」。用 CSS 就能做出这个味道：

// src/koi/playback/CharacterStage.tsx（片段）
// 关键：切表情前先加一个 120ms 的「僵直」，再换图，最后回正
const [freeze, setFreeze] = useState(false);
const prevEmotion = useRef(emotion);

useEffect(() => {
  if (emotion === prevEmotion.current) return;
  setFreeze(true);
  const t = window.setTimeout(() => {
    prevEmotion.current = emotion;
    setFreeze(false);
  }, 120);
  return () => window.clearTimeout(t);
}, [emotion]);

// 僵直时轻微上浮 1px + 亮度压暗，视觉上就是「屏住呼吸」
<div
  style={{
    transform: freeze ? 'translateY(-1px) scale(0.998)' : 'none',
    filter: freeze ? 'brightness(0.96)' : 'none',
    transition: 'transform 120ms ease-out, filter 120ms ease-out',
  }}
>
  <img src={spriteFor(emotion)} alt="" />
</div>

然后是镜片高光遮罩——视频里最省力的一手，你甚至不需要新立绘：

TIER 1：数值飘字要和表情同帧

// components/FloatingDelta.tsx —— 挂 300ms 就自己消失，不占布局
export function FloatingDelta({ label, value }: { label: string; value: number }) {
  const up = value > 0;
  return (
    <div style={{
      position: 'absolute', left: 24, top: 96,
      fontFamily: 'var(--font-hand, serif)',
      fontSize: 20, fontWeight: 700,
      color: up ? '#a3342b' : '#4a4a4a',
      animation: 'rise 1600ms cubic-bezier(.2,.9,.2,1) forwards',
      pointerEvents: 'none',
    }}>
      {label} {up ? '+' : ''}{value}
    </div>
  );
}
// index.css
// @keyframes rise {
//   0%   { opacity: 0; transform: translateY(8px) scale(.94); }
//   18%  { opacity: 1; transform: translateY(0)   scale(1.06); }  /* 弹一下 */
//   30%  { transform: scale(1); }
//   100% { opacity: 0; transform: translateY(-22px); }
// }

要写进剧本语法的是这一行：[mood:生气 亲密度-1]——把「情绪」和「数值变化」绑在同一条控制指令里，解析器一吐出来，舞台同时切表情、同时飘字。永远不会出现「表情已经变了但数字还没到」的错位，那正是活人感最容易被破坏的地方。

TIER 2：让台词接住玩家的话

视频里最能打的一句，实现起来其实非常土——正则：

// game/reply.ts —— 玩家输入 → 三类反应之一
const VAGUE = /^(喜欢|爱你|我爱你|想你|好可爱)[。!！~～]*$/;
const REPEAT = /(.)\1{3,}/;  // 同一字重复四遍以上，判定为敷衍

export function reactTo(raw: string) {
  const text = raw.trim();
  if (!text) return { line: '……你倒是说点什么啊。', mood: '无奈', delta: -1 };
  if (VAGUE.test(text)) {
    // 关键：把玩家的原话引用回去，再挑它的毛病
    return {
      line: `不……你说「${text}」，我也不知道是喜欢什么啊，宾语呢？`,
      mood: '挑眉',
      delta: 0,
    };
  }
  if (REPEAT.test(text)) return { line: '为什么又要说啊？', mood: '不耐烦', delta: -1 };
  return { line: pickByKeyword(text), mood: '平静', delta: +1 };
}

注意第三段 pickByKeyword 不必聪明。玩家不会去测你的覆盖度，只会记住被接住的那一次。十个关键词里接住三个，体感就已经「活」了；剩下七个走通用兜底，只要兜底台词有性格，没人会计较。

它的战斗系统自己承认「还没做完，大概看一下是什么类型就行」。跳跃式的功能堆叠（战斗、探索地图、技能、脱衣差分）在两周 Demo 里是加分项，在你这种要长期连载的卡里是维护债。

另外：「扔给 AI 写」在这个体量上行得通，但一旦要维护「亲密度 / 黏度 / 时间 / 体力」四个互相影响的数值，AI 生成的代码会很快变得没人看得懂。你的 parser.ts 已经是手写状态机，这条路是对的，别回头。

CHAPTER 05如果只记三句话

A活人感的单位是「帧」，不是「设定」

写一万字人设，不如让她在被冒犯的同一帧变脸 + 飘一个 -1。玩家信的是反应速度，不是背景故事。

B接住对方的话，比答对问题重要

「宾语呢？」这一句胜过一百句正确回答。让角色对玩家的表达方式有反应，而不只是对内容有反应。

C她得有自己的时间

DAY 1、体能 5/5、天黑了、次日——这些跟对话毫无关系的数字，才是「她不是为你待机」的证据。
